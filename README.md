# Auto Repair Evolution

Interfaz web estática y responsive creada para el Primer Examen Parcial de Diseño Web Adaptable.

## Tecnologías

- Vite
- TypeScript
- Tailwind CSS v4
- Design Tokens mediante `@theme`

## Ejecutar el proyecto

```bash
npm install
npm run dev
```

En PowerShell, si la ejecución de scripts está bloqueada, utiliza:

```powershell
npm.cmd install
npm.cmd run dev
```

## Diseño responsive

- Mobile: una columna y menú compacto.
- Tablet: dos columnas en contenido disponible.
- Desktop: tres columnas de servicios y navegación completa.

## Referencias de Figma

Las exportaciones Desktop, Tablet y Mobile deben colocarse en `public/figma-references`.

## Alcance

La interfaz es estática. No consume API ni implementa búsqueda, filtros o carga dinámica.
